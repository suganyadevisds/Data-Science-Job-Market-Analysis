# Data Science Job Market Analysis

## Project Overview

This project explores the Data Science job market using Microsoft Power
BI. It presents job-posting information through visualizations designed
to help users understand salary ranges, in-demand technical skills, and
hiring patterns.

## Objectives

-   Analyze salary distribution across job postings.
-   Identify commonly requested technical skills.
-   Explore job postings across available company and job-related
    categories.
-   Turn job-posting data into clear, useful visual insights.

## Tools and Technologies

-   Microsoft Power BI
-   Power Query
-   CSV data
-   Data visualization

## Dashboard Highlights

-   **KPI cards:** Summarize key information from the dataset.
-   **Salary distribution:** A histogram or column chart groups salaries
    into ranges.
-   **In-demand skills:** A bar chart compares how frequently skills
    appear in job postings.
-   **Job-market comparisons:** Visuals compare companies and other
    categories available in the dataset.
-   **Interactive exploration:** Filters and slicers help users explore
    the report.


## How to View

1.  Open the PDF report to view the dashboard pages.
2.  To interact with or edit the report, open the `.pbix` file using
    Power BI Desktop.
3.  If prompted, configure the data source path for the dataset.

## Key Skills Demonstrated

-   Data analysis and exploration
-   Data cleaning and transformation with Power Query
-   Creating calculated groupings such as salary bins
-   Building KPI cards, bar charts, and salary-distribution visuals
-   Designing a report for clear communication of insights
